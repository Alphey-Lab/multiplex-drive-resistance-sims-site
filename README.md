# Multiplex Drive Resistance Simulator — Public Site

This repository hosts the public static website for the **Multiplex Drive Resistance Simulator**.

## Use the simulator

Open the interactive simulator at:

```text
https://alphey-lab.github.io/multiplex-drive-resistance-sims-site/website/
```

The page runs one stochastic, in-silico simulation trajectory in your browser using Shinylive and Pyodide. On first use, the browser downloads the required runtime and simulation package, so initial loading can take a little longer.

## Scientific-use caveat

This simulator is intended for exploratory modelling and educational use. It is **not** a field-performance predictor, an experimental-authorization tool, or a regulatory decision tool. Results depend on the model assumptions, selected parameters, and stochastic variation; a single run does not quantify uncertainty across replicate simulations.

For scientific background, see Khatri and Burt, *Multiplexing guides can reduce resistance to gene drives*, PNAS (2022), DOI: `10.1073/pnas.2200567119`.
